# Dataset provenance, not architecture, determines what neural networks learn about human risky choice

用"训练好的神经网络当被试"的实验框架：在不同来源（provenance）的人类风险决策数据集与不同架构上训练同一批模型，再让每个模型通过同一套诊断探针电池，读出它"学到的理论"（CPT 坐标、行为效应指数、符号回归蒸馏出的闭式表达式），最后做双因素方差分解——数据来源解释的方差远大于架构解释的方差。

## 网格规模与架构（第三轮）

19 个数据臂 × **8 个架构** × 多 suite = **1,120 个训练单元**。架构参数量跨五个数量级，
所以「架构不重要」不再只是在小模型之间检验：

| 架构 | 参数量 | 归纳偏置 |
|---|---|---|
| CPT_NET | 6 | 可微 CPT，理论结构完全内建 |
| LINEAR | 56 | 展平特征上的线性 |
| MLP_S | 7,809 | 展平特征上的 MLP |
| SET | 16,897 | DeepSets，结果槽置换不变 |
| TRANSFORMER | 75,649 | 结果槽间自注意力 |
| MLP_L | 211,969 | 更深的 MLP |
| RESMLP | 2,134,529 | 宽残差 MLP，规模对照 |
| GBT | — | 梯度提升树，非神经网络基线 |

**学习率按架构校准**（`code/scripts/09_lr_calibration.py` → `code/src/models.ARCH_LR`），在与正式训练
相同的 600-epoch 预算下、用两个臂的方差归一化验证损失选出。这一步不是调优细节而是
公平性前提：原来所有架构共用 lr=3e-3，其中 SET 与 MLP_L 都没到自己的最优，RESMLP 直接
塌缩成常数。修正后 **SET 在 CPC18 上的测试误差改善 52–61%**，它此前 60–80% 的「塌缩」
主要是欠调参而非架构缺陷。校准必须与最终训练同预算——用 80-epoch 预算选 lr 会选出
让 SET 反而恶化 44% 的值（lr 与早停耦合）。

`GBT` 在全部四个主臂上都是最优模型（0.0092–0.0118），优于每一个神经网络。

## 读数能不能信：参数可恢复性标定（决定其余一切怎么读）

其余全部分析都假定拟合出的 CPT 坐标有意义。`build_sufficiency_arms()` 直接检验这个假定：
真值已知的 agent，只变题目数（60→1000）和每题被试数（8→128），看恢复误差。
20 个臂 × 8 架构 × 3 seeds。结果分两类，**而且平均误差会把这个结构平掉**：

| 参数 | 中位相对误差 | 随数据量改善？ |
|---|---|---|
| γ⁻ | **0.078** | 是 |
| α | **0.127** | 是（128 被试下 0.30→0.06） |
| λ | 0.162 | 弱 |
| γ⁺ | 0.219 | 弱 |
| **τ** | **0.357** | **否** |
| **β** | **0.396** | **否** |

**τ 和 β 在任何测过的数据量下都不可恢复**，误差停在 36–40% 不降。这不是样本量问题而是结构性
可辨识限制：τ 与价值尺度只能确定乘积，β 与 λ 在损失侧共线。加数据永远解决不了。

**这有个必须交代的下游后果。** 恢复误差是在合成臂上独立测定的（与真实数据分析无关），
所以可以合法地用它筛选参数。但把 H1 限制在"这套方法真能恢复的参数"上，结论会**翻转两次**：

| 筛选门槛 | 留下 | 数据集 ω² | 架构 ω² | 谁领先 |
|---|---|---|---|---|
| 全部 6 个 | 6 | 0.363 | **0.470** | 架构 |
| ≤30% | α λ γ⁺ γ⁻ | **0.340** | 0.332 | 数据来源 |
| ≤20% | α λ γ⁻ | **0.314** | 0.211 | 数据来源 |
| ≤15% | α γ⁻ | 0.327 | **0.423** | 架构 |

诚实的读法不是"筛选后 H1 成立"，而是：**CPT 坐标这条证据链的分辨力不足以支撑任何方向的结论**，
不应作为主要证据。不依赖拟合、直接从预测计算的**行为效应指数**才应该是主证据——
而它们一致显示架构主导（中位 0.497 vs 0.231）。

## 受控因子实验：把 provenance 从相关推到因果

观察性对比有个无法回避的弱点：choices13k 与 CPC18 在**题目池、每题被试数、题目总数、协议**上同时不同，
所以任何观察性拆分都说不清是哪一个让网络学到不同理论；而独立来源只有 2 个，这个质疑永远答不完。

`build_controlled_arms()` 用一个**真值已知**的 CPT agent 做 2⁴ 完全因子设计，每个因素独立操纵
（16 个合成臂 × 8 架构 × 5 seeds = 640 单元）。合成来源不受公开数据数量限制，且交叉完全、无混淆：

| 因素 | 两个水平 | 中位 ω² |
|---|---|---|
| **架构** | 8 个架构 | **0.768** |
| **generating agent** | Prelec γ=0.65（高估稀有）vs γ=1.0（线性） | **0.467** |
| 题目总数 | 182 vs 1500 | 0.209 |
| 题目池 | c13k 分布 vs CPC18 分布 | 0.062 |
| 每题被试数 | 16 vs 100（聚合噪声） | 0.005 |

**核心结论：「来源」的四个成分里，只有被试真实的行为差异有大效应**（0.467）；题目池（0.062）和
聚合噪声（0.005）几乎无效应，样本量居中（0.209）。也就是说，当 c13k 和 CPC18 的模型学到不同理论时，
那不是因为题目不同或噪声不同——这与图 7 的降采样/重加权对照（观察性）**独立收敛**。

两个支撑证据：
- `rare_event_index` 上 agent 的 ω² 达 **0.859**，探针准确读出了我按设计注入的 γ 差异
  （desc agent 0.093 → exp agent −0.008），且**两个题目池的曲线几乎平行**——题目池对 agent 效应无调节
- γ⁺ 恢复保序但**系统性低估**：真值 0.65 → 恢复 0.55，真值 1.00 → 恢复 0.92

**但架构（0.768）仍然大于任何单一来源成分。** 这是受控条件下的结论，比观察性结论更难反驳，
方向也一样：标题里 "not architecture" 的强形式仍不成立。

## 三个从数据里挖出来的结果

**图 11 · 抽象阶梯（部分成立，单调性不成立）。** 「来源赢还是架构赢」依赖于读出的抽象层级。
同一批 run、同一子集（n=276）：

| 读出层级 | 维度 | R²_来源 | R²_架构 | 来源/架构 |
|---|---|---|---|---|
| 原始探针响应 | 1742 | 0.195 | 0.434 | **0.45** |
| 行为效应指数 | 5 | 0.241 | 0.348 | **0.69** |
| CPT 理论坐标 | 6 | 0.204 | 0.313 | 0.65 |

从原始行为到抽象读出这一步是稳健的：架构份额从 0.434 掉到 0.31–0.35，比值从 0.45 升到
0.65–0.69（宽松筛选子集上 0.38 → 0.78）。**但行为指数与 CPT 坐标之间不再继续上升**
（0.69 → 0.65）。扩展到 8 架构、校准 lr 之前的三级单调结论（0.47→0.80→0.83）**没有复现**，
只能陈述为两级效应：原始行为由架构主导，抽象读出把这个优势削掉一半左右。
来源在任何层级都未超过架构，仍不支持标题里 "not architecture" 的强形式。

**图 11b–c · provenance 效应是局部的，不是全局的。** 对 1,742 个探针逐个做双因素分解，
架构在绝大多数探针上主导；来源只在 common-ratio（Allais）族反超，且架构优势在稀有概率区
最小、在高概率区最大。这解释了为什么 `rare_event_index`（0.694 vs 0.497）和
`certainty_index`（0.689 vs 0.485）是仅有的两个来源主导的行为读出量。

**图 12 · 经验梯度：两个独立设计上的复现（新）。** 把「经验」从二元标签展开成有序因子。
CPC18 的 5 个 block 是同一批人在同 210 题上的学习轨迹（within-problem）；choices13k 的
每道题只出现在一个 block，是 between-problem 对照，每级约 2,450 题。两者不共享题目、
被试或国家。趋势用架构内 Spearman ρ、再按架构平均，p 由架构内置换 block 标签得到：

| 读出量 | c13k ρ | CPC18 ρ | 结论 |
|---|---|---|---|
| `rare_event_index` | −0.258 (p=.002) | −0.376 (p<.001) | 同号，CPC18 上 **8/8 架构**同号 |
| `gamma_neg` | +0.321 (p<.001) | +0.536 (p<.001) | 同号，两边显著 |
| `reflection_index` | −0.178 (p=.025) | −0.190 (p=.010) | 同号，两边显著 |
| `gamma_pos` | −0.184 (p=.024) | +0.463 (p<.001) | **反号**，两边都显著 |

11 个读出量里 5 个同号。最强的是稀有事件指数随经验累积单调下降——这是描述-经验差距
**形成过程**的直接证据，且在两个不共享任何东西的设计上复现。`gamma_pos` 的反号是
真实分歧，需在正文交代，不应掩盖。

**图 7 · 差异不能归因于样本量。** 把 c13k 降采样到 CPC18 的 182 题并没有把它变成
CPC18——λ 反而 overshoot 到 1.41（CPC18 为 1.07），τ 朝反方向走到 6.1（CPC18 为 14.7），
特征重加权几乎不动。**图 10** 给出人群效应的基准尺度：同题同协议只换实验室，τ 差 38%。

试过但不成立、因此没有写进图表的方向：架构对 provenance 的敏感度。
GBT 是确定性的、种子内散布为 0，敏感度/噪声比会爆成 1e16；而且原始敏感度排序
（SET 3.63 > GBT 3.14 > CPT_NET 2.71 > MLP 1.9–2.1）否定了「归纳偏置强则更鲁棒」的直觉。

## 可辨识性筛选（必读）

在 182 题的 CPC18 臂上，部分架构训练后在整套探针上几乎输出常数（`probe_sd` 低至 0.002），
此时 CPT 拟合的六个坐标完全不受约束，优化器只会把参数推到箱约束边界上。若把这些"坐标"
原样送进方差分解，分解的是噪声而不是理论差异。因此 `03` 为每个 run 记录两个判据：

- `identifiable`：`probe_sd >= 0.02`，即网络对探针电池有反应。**行为指数**用它（指数直接从
  预测算出，不经过 CPT 拟合），主网格保留 216/240。
- `theory_identifiable`：在上面基础上，还要求没有任何参数贴在箱约束上。**CPT 坐标**用它，
  主网格保留 196/240。

`06` 在双因素设计里若发现某架构在某个臂上存活数 < 3 就整列剔除，并在
`h1_variance_decomposition.csv` 的 `dropped_archs` 列写明。当前 CPT 坐标分析因此丢掉了
LINEAR 与 SET（两者正是在小臂上学不到东西的架构），这会压低架构一侧的方差，需在正文说明。

## 当前跑出的结果（与标题的关系）

跑完整条流水线得到的 H1 是**混合**的，不支持"数据来源远大于架构"这一强形式：

| 读出量族 | 保留 | 数据集 ω² 中位 | 架构 ω² 中位 | 数据集领先的项 |
|---|---|---|---|---|
| CPT 坐标（剔 LINEAR/SET） | 150 | 0.767 | 0.628 | 3/6 |
| 行为指数（保留 6 架构） | 216 | 0.409 | 0.569 | 2/5 |

多变量指纹上架构反而更强：PERMANOVA 架构 F=34.6 vs 数据集 F=13.9；silhouette 按架构
0.213 vs 按数据集 0.087。数据集明确占优的是稀有事件与确定性效应（ω² 0.76 / 0.81，
对应架构 0.56 / 0.57），架构占优的是决策温度 τ、reflection 与 EV 一致性。

H3 的符号翻转在 4/6 架构上成立；H4 的迁移矩阵强不对称（c13k 训练 0.62–0.84，
CPC18 训练 0.13–0.40），但这与 CPC18 仅 182 题高度混淆，需结合 size_control 对照解读。
